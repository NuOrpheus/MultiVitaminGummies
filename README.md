​This is a very short visual novel that is currently in development. The aim of this project is to be used as a template for other visual novels. The gimmick of this particular template is that all the dialogue and decision trees are stored in a .csv file as to allow for multiple people to edit it at once. 

This is in Alpha, the Beta will be released on the 26th of April.

Playable on browser at [itch.io](https://nuorpheus.itch.io/multi-vitamin-gummies).
